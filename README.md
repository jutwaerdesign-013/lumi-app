# KIMPACT — met Lumi
Kleine prikkels. Eigen beweging.

Prototype: open index.html in een moderne browser of host als statische website. Nog niet op Android getest. Geen build of externe dependencies.

Foto- en tekstnotities worden in IndexedDB van deze browser opgeslagen. Dit is geen versleutelde kluis of gegarandeerde back-up. Gebruik geen gedeeld apparaat voor gevoelige inhoud. Exporteer regelmatig; verwijderen van browsergegevens wist het dagboek. JSON-export bevat ook foto's en is niet versleuteld. Import herstelt entries en slaat bestaande IDs over.

Aanwezig: foto-upload/camera-invoer, tekstnotities, energie, dagelijkse opdracht, willekeurige opdracht, drie reflectiekaarten, weekreflectie, tijdlijn, individuele verwijdering, export/import.

Niet aanwezig: automatische notificaties, mailbriefing, cloudsync, AI-beeldanalyse, externe beeldselectie, audio-opname, offline-serviceworker. Dagelijkse opdracht verschijnt alleen bij openen. Lumi interpreteert geen emoties uit beelden. Theoriekaarten zijn reflectiehulpen, geen behandeling.

Bronnen kaarten: https://jamesclear.com/atomic-habits-summary ; Maslow, A.H. (1943), A Theory of Human Motivation (historisch reflectiekader, geen vaste verplichte ladder); https://www.cci.health.wa.gov.au/Resources/Looking-After-Yourself/Depression

Handmatige test: sla tekst en een kleine foto op, herlaad, controleer tijdlijn, exporteer, verwijder entry, importeer export en controleer herstel. Publiceren en mobiele tests moeten nog gebeuren.
